# 参考実測値（軽さの確認）

測定環境: Windows 11 Home / GPU RTX 5060 / 論理 16 CPU / Node.js v24.19.0 / iPhone 15 / Chrome。
**値は環境・iOS・画面内容で変わります。** 「このくらいの軽さ」という目安です。測定日 2026-10-02。

## 起動・待機

| 項目 | 結果 |
|---|---|
| 起動 →（UI が HTTP 200 を返す）まで | 約 0.6 秒 |
| 待機中（「ミラーリング開始」後、広告中）メモリ（Working Set） | 約 43 MB |
| 待機中 CPU | 約 0.02%（全体比。1 コア換算でも 1% 未満） |
| Node プロセス数 | 1（スレッド 17 前後） |

## ミラーリング中（偽 iPhone による H.264 テストストリーム 590×1278・30fps、Chrome 側でデコード）

| 項目 | 結果 |
|---|---|
| メモリ（Working Set） | 約 55 MB |
| CPU（Node） | 約 0.1% 未満（全体比）。AES 復号と転送だけで、デコードは Chrome（GPU）側 |
| GPU（nvidia-smi、システム全体） | 使用率 約 4%、デコーダ 約 7% |
| プロセス数 | 1（Node）＋ブラウザ |

実機 iPhone での値は下の「実機」欄を参照（測定後に追記）。

## 繰り返し接続の耐久テスト（自動、偽 iPhone）
通常切断 25 回 ＋ 通信を突然切る 15 回（Wi-Fi 断に近い）を連続実行（約 2.5 分）:

| 項目 | 開始 | 終了 |
|---|---|---|
| メモリ（WS） | 50.7 MB | 59.1 MB（増加は小さく、GC で上下） |
| ハンドル数 | 300 | 295 |
| スレッド数 | 17 | 13 |
| 累積 CPU 時間 | 0.4 秒 | 2.3 秒（約 40 セッション分） |
| 復号エラー（bad NAL） | — | 0 |
| ログ | — | 約 190 KB（1 MB で自動ローテーション、1 世代のみ保持） |

WASM インスタンスは復号ごとに作り直しますが（呼び出し間の内部状態を持ち越さないため）、上記のとおりメモリ増加は見られませんでした。

## 通信
- ミラーリング中の Node の ESTABLISHED 接続は `127.0.0.1`（ブラウザ・テスト）のみ。外部サーバーとの接続はありません。
- 待受け: `127.0.0.1:7878`（UI）、TCP 7000 / 7100（AirPlay・「ミラーリング開始」中のみ）、UDP 5353 / 7101–7103。
- テレメトリ・更新確認・クラウド通信のコードはありません。

## 実機（iPhone 15、Chrome を F11 全画面、約 1 分・配布 ZIP を別フォルダに展開し同梱 node.exe で実行）

| 項目 | 結果 |
|---|---|
| 待機中メモリ（平均 / 最大、約 2 分） | 54.7 / 55.5 MB |
| 待機中 CPU（全体比、平均 / 最大） | 0.006% / 0.04% |
| 接続中メモリ（平均 / 最大） | 60.2 / 63.6 MB |
| 接続中 CPU（全体比、平均 / 最大） | 0.07% / 0.16% |
| GPU（システム全体、接続中） | 使用率 平均 3%（最大 5%）、デコーダ 平均 約 2% |
| 受信フレーム | 画面が動いている間 約 30〜34 フレーム / 5 秒（画面が静止すると減る） |
| Node の ESTABLISHED（接続中） | `127.0.0.1`（ブラウザ）と、iPhone（同じ LAN 内のアドレス）のみ。インターネット側の相手はなし |

※ 待機中メモリは起動時期や直前の接続回数で 43〜55 MB の幅があります。ブラウザ（Chrome）側の使用量は含みません。
